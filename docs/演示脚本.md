# 60 秒演示脚本

用于录屏展示，或当面演示。

| 时间 | 操作 | 说明 |
|---|---|---|
| 0-8s | 展示目录 | `pipeline.py`、`filter-rules.json`、`data/events.jsonl` |
| 8-15s | `head -3 data/events.jsonl` | 输入是 OneBot 事件，里面有重复、营销群、图片消息 |
| 15-35s | `python3 pipeline.py data/events.jsonl` | 去重 → 过滤 → 入库 → 生成日报，每步都有输出 |
| 35-50s | `cat 日报-*.txt` | 结果：只保留需要注意的消息，并标出命中关键词 |
| 50-60s | 展示 `filter-rules.json` | 规则外置，改规则不用改代码 |

录制注意：不要出现真实聊天内容、联系人和群名；仓库里的数据全是假的。
